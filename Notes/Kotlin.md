# Kotlin

Kotlin is a new (not anymore) programming languages developed by Jetbrains! It runs on the JVM and was initially designed to tackle the problems of Java. Kotlin is staticly typed and extremely null safe in it's design with a easy to understand syntax. Kotlin can be thought of pythonlike but with all the features of java. Kotlin is currently the defacto standard for android app developmen. Kotlin code can also be translated into Java.

Kotlin is both Object Oriented and Functional language. Kotlin is interchangeable with Java, again this is very important. 
Kotlin can also be used for multiplatform app development.
